# BSD3513 Lab Report 4 – Neural Network Activation Functions

## Files
- `relu_app.py` – ReLU activation function visualisation
- `sigmoid_app.py` – Sigmoid activation function visualisation
- `tanh_app.py` – Tanh activation function visualisation
- `requirements.txt` – required Python packages

## Run locally
Open PowerShell or Terminal in this folder and install the packages:

```bash
python -m pip install -r requirements.txt
```

Run each application separately:

```bash
python -m streamlit run relu_app.py
python -m streamlit run sigmoid_app.py
python -m streamlit run tanh_app.py
```

Stop an app with Ctrl+C. Run only one command at a time.

## Deployment and GitHub
Create a GitHub repository and upload these files. For each app, create a Streamlit Community Cloud deployment and select its corresponding Python file as the app entry point. Copy the public app URL(s) and repository URL into the report. Deployment requires the student's own GitHub/Streamlit account.
